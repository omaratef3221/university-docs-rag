## Developing an industry 4.0 - Driven parking enforcement system

This project aims to develop an Industry 4.0-driven parking enforcement system by integrating IoT, AI, and license plate recognition technologies. It addresses inefficiencies in manual parking patrols, reduces worker exposure to extreme weather, and supports the UAE’s smart city vision. A functional prototype was developed using RFID simulation and sensors, while a full real-world system was conceptually designed.
